# 企业官网全栈项目
## 项目介绍
前后端分离企业客服官网，集成DeepSeek AI智能客服、访客留言提交、管理员JWT权限后台，完整覆盖数据库设计、接口开发、前后端联调全流程。
## 技术栈
前端：Next.js + TypeScript + TailwindCSS
后端：Java SpringBoot + Spring Security + Spring Data JPA
数据库：MySQL 8.0
第三方：DeepSeek大模型API、JWT令牌鉴权
## 功能模块
1. 企业首页、产品展示静态页面
2. AI在线客服对话（含异常降级兜底）
3. 访客留言表单提交
4. 管理员登录、留言管理后台
